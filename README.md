# 巷伴互助網站：部署說明（正式版）

這個資料夾是完整的網站：畫面、資料處理程式、系統檢查頁。放到 Vercel 之後，任何人不用登入 Claude 就能使用。

## 資料夾裡有什麼

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站本體（3D 村莊、註冊、後台） |
| `status.html` | 系統狀態檢查頁（網址是 `你的網站/status`） |
| `api/app.js` | 資料處理程式（註冊、登入、留言、管理者） |
| `package.json` | 告訴 Vercel 要安裝儲存空間的工具 |
| `vercel.json` | 網站設定 |

## 第一次部署（約 15 分鐘）

### 1. 把檔案放到 GitHub
1. 到 GitHub，在你原本的 `xiangban-demo` 專案裡，按 **Add file → Upload files**。
2. 把這個資料夾裡的**所有檔案和 `api` 資料夾**一起拖進去（`api` 資料夾可以直接拖）。
3. 它會問要不要覆蓋同名檔案，選覆蓋。按 **Commit changes**。
4. 確認專案首頁看得到：`api` 資料夾、`index.html`、`status.html`、`package.json`、`vercel.json`。

Vercel 會自動重新部署。

### 2. 建立儲存空間（存居民資料的地方）
1. 到 Vercel，進入你的專案，上方分頁點 **Storage**。
2. 按 **Create Database**，選 **Blob**。
3. 如果有「Private / Public」選項，選 **Private**。名稱隨意。按建立。
4. 出現 **Connect Project** 時，選你的專案，Production、Preview、Development 三個都勾，按 **Connect**。

### 3. 設定管理者密碼
1. 專案頁 → **Settings** → **Environment Variables**。
2. **Key** 填 `ADMIN_PASSWORD`，**Value** 填你要的管理者密碼，三個環境都勾，按 **Save**。
3. 密碼請用 **8 個字以上**。管理者看得到所有居民資料，不要用 `xiangban` 這種太容易猜的。
4. 這個密碼只存在 Vercel，網頁裡完全沒有。大小寫不拘，空格和橫線會被忽略。

### 4. 重新部署一次，讓設定生效
**Deployments** 分頁 → 最新一筆右邊的「⋯」 → **Redeploy**。等 1 分鐘。

### 5. 檢查有沒有設定好
開 `你的網站/status`。每一項都是綠色 ✅ 就完成了。
有紅色 ❌ 的項目，頁面上會寫出要怎麼做。

## 日常使用

- **居民**：打開網站 →「我是居民」→ 第一次來就填資料、設 4 位數密碼、蓋房子。下次回來選「我已經有家了」，輸入稱呼和密碼。
- **據點工作人員**：打開網站 →「我是據點管理者」→ 輸入管理者密碼。可以看統計、供需配對、居民名單、留言，匯出表格（CSV）。
- **居民忘記密碼**：管理者在後台「居民」分頁，按那位居民的「重設密碼」，會顯示一組新的 4 位數字，請當面告訴他。他登入後可以在口袋手機「設定」改成自己的。
- **居民想刪除資料**：口袋手機 →「設定」→「刪除我的帳號」。

## 資料怎麼保護

- 密碼不會被存成原文，存的是加過鹽的雜湊值，連管理者都看不到居民的密碼。
- 居民輸錯 5 次會鎖 15 分鐘，管理者輸錯 5 次也是，避免被人一直猜。
- 居民的稱呼、本事、房子，同村的鄰居和管理者看得到。這件事在註冊時有請居民勾選同意。
- 留言板是公開的，同村的人都看得到，不是私訊。
- 管理者登入 8 小時後自動登出。
- 這是給社區據點使用的輕量系統，**不要請居民填身分證字號、地址、電話**。

## 備份

後台的「匯出」可以隨時下載居民名單和留言（CSV）。建議每個月備份一次。

## 常見問題

**Q：資料會不會不見？**
存在 Vercel Blob，不會因為重新部署而消失。刪除專案或刪除 Storage 才會不見。

**Q：要付錢嗎？**
Vercel 的免費方案（Hobby）有提供 Blob 的免費額度，這種小規模使用通常用不完。但 Hobby 方案規定只能用在**非商業用途**。如果之後要正式對外營運，請查 Vercel 最新的使用條款和價格。

**Q：想換管理者密碼？**
Settings → Environment Variables → 改 `ADMIN_PASSWORD` → Redeploy。

**Q：網站打開了，但註冊時說連不上伺服器？**
開 `/status` 看哪一項是紅色。最常見的是還沒 Redeploy。
